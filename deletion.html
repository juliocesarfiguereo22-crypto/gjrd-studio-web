Instrucciones para la eliminación de datos

GJRD STUDIO

Última actualización: 25 de noviembre de 2026.

1. Eliminación de datos de Facebook

Los usuarios pueden retirar la autorización concedida a GJRD STUDIO y eliminar las credenciales locales asociadas a su cuenta de Facebook.

  1. Abre GJRD STUDIO.
  2. Entra en la sección Compartir.
  3. Desactiva la publicación automática de Facebook.
  4. Desconecta la cuenta de Facebook.
  5. Accede a la configuración de Facebook.
  6. Busca Aplicaciones y sitios web o Integraciones comerciales.
  7. Localiza GJRD STUDIO y elimina su autorización.

Abrir configuración de Facebook

2. Eliminación de datos de TikTok

Desconecta TikTok desde GJRD STUDIO y revoca los permisos de la aplicación desde las opciones de seguridad de tu cuenta de TikTok.

3. Eliminación de datos de Telegram

Desactiva los envíos automáticos y desconecta Telegram desde la sección Compartir. Si deseas invalidar el token de tu bot, puedes hacerlo mediante BotFather.

4. Eliminación de archivos locales

Los vídeos, clips, subtítulos, portadas, preferencias y registros de publicación pueden permanecer almacenados en el ordenador.

El usuario puede eliminar estos archivos desde la biblioteca de GJRD STUDIO, cuando exista esa opción, o directamente desde las carpetas de almacenamiento correspondientes.

Antes de eliminar archivos, se recomienda realizar una copia de seguridad del contenido que se desee conservar.

5. Solicitud de eliminación de datos

Si necesitas asistencia para eliminar tus datos asociados a GJRD STUDIO, puedes enviar una solicitud al siguiente correo electrónico:

juliocesalfiguereo@hotmail.com

Incluye en tu solicitud:

  • Asunto: Eliminación de datos de GJRD STUDIO.
  • Plataforma o cuenta relacionada.
  • Descripción de los datos que deseas eliminar.

No envíes contraseñas, tokens de acceso ni otras credenciales privadas.

La solicitud será revisada y se proporcionarán las instrucciones correspondientes para eliminar los datos aplicables.

6. Contenido publicado en redes sociales

Desconectar GJRD STUDIO o eliminar archivos locales no elimina automáticamente los vídeos publicados en Facebook, TikTok o Telegram.

El usuario deberá gestionar la eliminación de dichas publicaciones directamente desde la plataforma correspondiente.
