Creación y edición de clips para Windows

¿Qué es GJRD STUDIO?

GJRD STUDIO es una aplicación de escritorio para Windows diseñada para grabar transmisiones, procesar vídeos, generar clips, añadir subtítulos y organizar contenido.

Funciones principales

Grabación de transmisiones, generación de clips, edición de vídeos, subtítulos y biblioteca multimedia.

Integración con redes sociales

GJRD STUDIO está desarrollando integraciones para permitir que los usuarios conecten sus propias cuentas y publiquen contenido mediante autorización oficial.
