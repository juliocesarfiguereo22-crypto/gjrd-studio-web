Política de privacidad de GJRD STUDIO

Última actualización: 25 de noviembre de 2026.

1. Sobre la aplicación

GJRD STUDIO es una aplicación de escritorio para Windows diseñada para grabar transmisiones, generar clips, editar vídeos, crear subtítulos y portadas, y preparar o publicar contenido en redes sociales.

2. Información utilizada

Según las funciones autorizadas, GJRD STUDIO puede procesar identificadores de cuentas y páginas, nombres públicos, permisos, tokens de acceso, identificadores de publicaciones, archivos multimedia, transcripciones y estados de publicación.

3. Integración con Facebook y Meta

GJRD STUDIO utiliza las interfaces oficiales de Meta para gestionar páginas autorizadas, publicar vídeos y Reels, enviar portadas y consultar estados de publicación.

Los datos obtenidos mediante Meta se utilizan para proporcionar las funciones solicitadas por el usuario. La aplicación no vende estos datos ni los utiliza para publicidad personalizada.

La publicación automática requiere autorización previa del usuario y puede desactivarse desde la aplicación.

4. Integración con TikTok

GJRD STUDIO incorpora una integración con TikTok sujeta a los permisos y aprobaciones correspondientes. La aplicación utiliza los mecanismos oficiales de autorización y solicita los permisos necesarios para las funciones seleccionadas.

La autorización local de TikTok está diseñada para mantenerse durante la sesión activa. Al cerrar la aplicación, las credenciales conservadas en memoria dejan de estar disponibles.

5. Integración con Telegram

El usuario puede configurar voluntariamente un bot de Telegram para enviar vídeos y portadas a su chat personal. Para ello, la aplicación utiliza el token del bot y el identificador del chat autorizado.

6. Almacenamiento y seguridad

Los vídeos, clips, subtítulos, portadas, preferencias y registros de publicación se almacenan localmente en el dispositivo del usuario.

Las credenciales persistentes de Facebook y Telegram se almacenan mediante el sistema de credenciales del sistema operativo.

GJRD STUDIO no solicita directamente las contraseñas personales de Facebook ni de TikTok.

7. Procesamiento mediante inteligencia artificial

Las funciones de transcripción, análisis de contenido, generación de subtítulos y creación de portadas utilizan herramientas de procesamiento local. Algunas funciones pueden requerir descargar modelos o recursos necesarios para su funcionamiento.

8. Comunicación con servicios externos

Cuando el usuario autoriza una publicación o un envío, los archivos multimedia y los datos necesarios se transmiten a la plataforma seleccionada. Dichas plataformas aplican sus propias políticas de privacidad y condiciones del servicio.

Consulta las políticas de: Meta, TikTok y Telegram.

9. Conservación y eliminación de datos

Los archivos y registros locales se conservan hasta que el usuario los elimina. Las credenciales persistentes se conservan hasta que se desconecta la integración, se eliminan las credenciales o dejan de ser válidas.

El usuario puede solicitar la eliminación de datos, desconectar las cuentas vinculadas y revocar los permisos desde las plataformas correspondientes.

La eliminación de archivos locales no elimina automáticamente las publicaciones realizadas en servicios externos.

10. Derechos y control del usuario

El usuario puede solicitar información sobre el tratamiento de sus datos, su corrección o eliminación, así como retirar las autorizaciones concedidas a GJRD STUDIO.

11. Contacto

Para consultas sobre privacidad o solicitudes de eliminación de datos, puedes escribir a: juliocesalfiguereo@hotmail.com.

12. Cambios en esta política

Esta política podrá actualizarse cuando se incorporen nuevas funciones o cambien los tratamientos de datos. La versión vigente estará disponible en esta página.
